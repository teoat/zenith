## 📊 Analytics APIs

### Dashboard APIs
- `GET /analytics/overview` - System-wide analytics overview
- `GET /analytics/cases` - Case-specific analytics and metrics
- `GET /analytics/transactions` - Transaction pattern analysis
- `GET /analytics/fraud` - Fraud detection statistics and trends

### Reporting APIs
- `POST /reporting/generate` - Generate custom reports
- `GET /reporting/templates` - List available report templates
- `GET /reporting/{id}` - Retrieve specific report details
- `POST /reporting/{id}/export` - Export report in various formats

### Statistics APIs
- `GET /stats/performance` - System performance statistics
- `GET /stats/users` - User activity and engagement statistics
- `GET /stats/cases` - Case resolution and backlog statistics
- `GET /stats/compliance` - Compliance and regulatory statistics

### Scheduled Reporting APIs
- `GET /reporting/scheduled` - List scheduled reports
- `POST /reporting/scheduled` - Create new scheduled report
- `PUT /reporting/scheduled/{id}` - Update scheduled report configuration
- `DELETE /reporting/scheduled/{id}` - Remove scheduled report
