# Internal Archives

Overview
--------
This folder contains archived snapshots, backups and raw outputs. Originals are preserved here for provenance and audit purposes.

Contents (examples)
-------------------
- `orchestration_plan_archived.md` — archived orchestration plan
- `api/README_backup.md` — archived API backup
- `reports/consolidated_reports.md` — historical consolidated reports

How to use
----------
- Consult archives for historical diffs, regulatory audits or to restore older files. Active documentation lives at the top-level indexes in `docs/`.
