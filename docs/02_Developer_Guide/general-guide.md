# General Developer Guide

## Overview
This guide provides comprehensive information for developers working on the 378x492 Fraud Detection Platform.

## Getting Started
- Clone the repository
- Set up development environment
- Configure local dependencies
- Run tests

## Architecture
- Backend: FastAPI with PostgreSQL and Redis
- Frontend: React with TypeScript
- Desktop: Electron wrapper
- AI/ML: Custom fraud detection engine

## Development Workflow
1. Create feature branch
2. Implement changes
3. Write tests
4. Submit pull request
5. Code review and merge

## Key Technologies
- Python 3.11+ for backend
- Node.js 18+ for frontend
- Docker for containerization
- GitHub Actions for CI/CD

## Best Practices
- Follow code style guidelines
- Write comprehensive tests
- Document API changes
- Use type hints and interfaces
- Handle errors gracefully
