# 378x492 Fraud Detection Platform

Comprehensive fraud detection system with advanced graph analysis and reconciliation capabilities.

## Architecture

*   **Frontend**: React + Vite application (`/frontend`)
*   **Backend**: Python FastAPI application (`/backend`)

## Key Features

*   **Fraud Detection Engine**: Real-time transaction monitoring and rule-based flagging.
*   **Network Analysis**: Graph-based visualization of entity relationships.
*   **Data Ingestion Wizard**: Streamlined workflow for uploading and mapping financial documents (`/frontend/ingestion`).
*   **Reconciliation**: Automated matching of bank statements against internal ledgers.
*   **10/10 Vision**: Converged Fraud & AML Intelligence ([docs/architecture/VISION_10_10.md](docs/architecture/VISION_10_10.md)).
